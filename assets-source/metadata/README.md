# Asset metadata

Exercise assets are not publishable until their provenance and human review are recorded here and the corresponding manifest entry is enabled.

For each exercise, record its ID, written movement instructions, exact spoken transcript (`voiceTextJa`), VOICEVOX version, character, style, generation date, normalization settings, measured duration, and applicable terms links. Record the reviewer and review date for both instruction clarity without images and listening quality (pronunciation, pacing, intelligibility, and clipping). Set `instructionReviewed` and `audioReviewed` only after those checks pass.

Do not generate or add exercise images, image prompts, or image-model metadata. Application icons are separate from exercise media.
